# C backend tests

This directory contains 3 harnesses for regression testing the 
`lucidcc` C backend over programs in `examples/lucidcc`. Programs' behavior 
(on the interpreter and the DPDK driver) is tested by `test/ltf`; the tests 
here check the generated C and what is specific to each driver.

- **Compiler tests** `test_compiler.py`: generate C from Lucid, compile it, 
  and compare the program part of the C against expected output. This 
  catches code that doesn't compile, and also any changes to lucidcc that 
  affect the c code (which is sometimes intended). A program marked 
  `// LUCIDCC_REJECT: <substr>` must instead be rejected with an error 
  mentioning `<substr>`.

- **PCAP tests** `test_pcap.py`: test the PCAP driver's virtual clock. Run 
  `delay` with the PCAP driver and compare its output packets and their 
  departure times against `_pcaps/<name>.expected.pcap`, generated by 
  `gen_pcaps.py`. `VARIANTS` in `test_pcap.py` runs a program on another test 
  case with extra driver arguments (`--latency-ns`).

- **RAWSOCK tests** `test_rawsock.py`: run a reflector test and a 
  recirculation loop test on the raw socket driver, to check 
  basic IO and concurrency. 


## Layout

- `examples/lucidcc/` (at the repo root) — the `.dpt` sources under test, shared with `test/ltf`.
- `expected/` — checked-in expected C, one `<name>.cc` per program (for `test_compiler.py`): 
  just the generated file's `program code` section, which is the same for every driver.
- `gen_pcaps.py` — generates the pcap test cases (`<name>.in.pcap` + `<name>.expected.pcap`).
- `_rawsock_build/` and `_pcaps` — untracked staging dirs.

## Usage

`make test-cc` runs the compiler and pcap tests; `make test-cc-rawsock` runs the
raw-socket driver tests. (The DPDK driver is tested by `make test-ltf-dpdk`.) Or run
each directly:

```sh
# compiler tests
./test/lucidcc/test_compiler.py              # build lucidcc and compile + diff every program
./test/lucidcc/test_compiler.py --update     # update expected C output

# pcap driver tests
./test/lucidcc/test_pcap.py                  # generate test cases, run + compare each

# driver tests: generate the C on the host (--gen), then run
python3 test/lucidcc/test_rawsock.py --gen
sudo python3 test/lucidcc/test_rawsock.py                    # reflector + scanloop over veths
```
