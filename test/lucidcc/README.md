# C backend tests

This directory contains 4 harnesses for regression testing the 
`lucidcc` C backend over programs in `./programs`.

- **Compiler tests** `test_compiler.py`: generate C from Lucid, compile it, 
  and compare against expected output. This catches code that doesn't compile, 
  and also any changes to lucidcc that affect the c code 
  (which is sometimes intended).

- **PCAP tests** `test_pcap.py`: compile and test programs with the PCAP driver; 
  compare output packets against `_pcaps/<name>.expected.pcap`. The expected 
  outputs are generated by `gen_pcaps.py`. This catches changes to lucidcc
  that affect program semantics, but not timing. 

- **RAWSOCK tests** `test_rawsock.py`: run a reflector test and a 
  recirculation loop test on the raw socket driver, to check 
  basic IO and concurrency. 

- **DPDK tests** `test_dpdk.py`: run the reflector test in the DPDK 
  driver in PCAP mode and af_packet mode; run the recirc. loop test 
  in PCAP mode; run an event test with a slightly more complicated 
  forwarding behavior. Runs in the `docker/dpdk` image.

## Layout

- `programs/` — the `.dpt` sources under test.
- `expected/` — checked-in expected C, one `<name>.cc` per program (for `test_compiler.py`).
- `gen_pcaps.py` — generates the pcap test cases (`<name>.in.pcap` + `<name>.expected.pcap`).
- `_rawsock_build/`, `_dpdk_build/`, and `_pcaps` — untracked staging dirs.

## Usage

`make test-cc` runs the compiler and pcap tests; `make test-cc-rawsock` and
`make test-cc-dpdk` run the driver tests. Or run each directly:

```sh
# compiler tests
./test/lucidcc/test_compiler.py              # build lucidcc and compile + diff every program
./test/lucidcc/test_compiler.py --update     # update expected C output

# pcap test cases
./test/lucidcc/test_pcap.py                  # generate test cases, run + compare each

# driver tests: generate the C on the host (--gen), then run
python3 test/lucidcc/test_rawsock.py --gen
sudo python3 test/lucidcc/test_rawsock.py                    # reflector + scanloop over veths
python3 test/lucidcc/test_dpdk.py --gen
docker/dpdk/run.sh test/lucidcc python3 test_dpdk.py         # reflector + af_packet + events + scanloop
```
